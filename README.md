# 🎓 CodewithJudy – School Management System

A responsive school management application built with **React** for managing student records, enrollment, and academic performance.

## ✨ Features

- **Dashboard:** View student statistics and academic performance.
- **Student Management:** Search, filter, and browse student records.
- **Enrollment:** Add new students with form validation.
- **Student Profiles:** View individual student information.
- **Record Management:** Edit and delete student records.
- **Data Persistence:** Save student records using Local Storage.
- **Performance:** Optimised rendering with `React.memo`, `useMemo`, and `useCallback`.
- **Responsive Design:** Clean interface with sidebar navigation.

## 🛠️ Built With

- React
- JavaScript (ES6+)
- CSS3
- Lucide React

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/a2-112/School-management.git
```

Navigate into the project folder:

```bash
cd School-management
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
